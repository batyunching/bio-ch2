## 目前進度：第 4 期（賓果競技場）完成

### 第 4 期：賓果競技場（`#/bingo`）
- 老師大屏 `#/bingo/host`：選題目範圍、難度、作答秒數、輪流方式 → 建立房間（4 位數房號＋QR Code）→ 開始遊戲
- 學生平板 `#/bingo/join/房號`：輸入班級、座號、姓名加入；每人隨機 5×5 賓果卡；以班級＋座號辨識，斷線重連會恢復原卡與已畫的 X
- 搖獎機抽球 → 大屏與該生平板同步出題、倒數 → 答對全班可畫 X；答錯或逾時號碼球放回，下次抽到換同單元新題
- 每完成一條線得一顆糖果；榮譽榜依完成時間排序、冠軍皇冠；連線時全螢幕煙火、鼓聲、歡呼、掌聲與語音念出姓名
- 遊戲結束可匯出 CSV（班級、座號、姓名、連線數、糖果數、答題紀錄）
- 雲端同步：Firebase Realtime Database＋匿名登入（設定碼放在 index.html 的 `FIREBASE_CONFIG`）
- 單機示範模式：不需 Firebase，同一台電腦開兩個以上分頁即可試玩

## 怎麼開啟
直接雙擊 `index.html` 用 Chrome／Edge 開啟即可。
網址格式：`index.html#/unit/2-2`、`#/unit/2-3`、`#/unit/2-4`（可直接放上 GitHub Pages）。

## 老師模式鍵盤操作
- `→` 或 `空白鍵`：下一點　`←`：上一點
- `PageDown`／`PageUp`：下一張／上一張卡（簡報筆通常就是這兩個鍵）
- `Esc`：關閉卡片

## 字型
標題使用「俐方體 11 號」像素字型（SIL OFL 授權，從網路載入）；沒有網路時會自動改用一般黑體。
